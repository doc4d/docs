In 4D, **sessions** are execution contexts with specific properties, features, and access privileges that control data access, store and share values between user processes and, in general, handle the user requests to your application. 

4D supports several types of sessions:

- **Web sessions**: Web user sessions are available when scalable sessions are enabled in your project. They are used for Web and REST connections, and can be assigned privileges.
- **Remote sessions**: In client/server applications, remote users have their own sessions managed on the server.
- **Stored procedures sessions**: All stored procedures executed on the server share the same virtual user session.
- **Standalone sessions**: Local session object returned in single-user application (useful in development and test phases of client/server applications).
