Fichiers sources

Ces clés désignent les applications sources (4D Volume Desktop, 4D Server) et les icônes utilisées pour la génération. Elles sont situées sous le nœud <SourcesFiles>, dans un sous-nœud <RuntimeVL> pour les applications monoposte et dans un sous-nœud <CS> pour les applications client/serveur.

Tous les chemins peuvent être absolus ou relatifs au fichier de structure. Une clé ...IncludeIt à True est requise pour que l'application correspondante soit incluse dans la génération.

Application monoposte (RuntimeVL)​

<Preferences4D>
  <BuildApp>
    <SourcesFiles>
      <RuntimeVL>
        <RuntimeVLIncludeIt>True</RuntimeVLIncludeIt>
        <RuntimeVLWinFolder>C:\4D\4D Volume Desktop\</RuntimeVLWinFolder>
        <RuntimeVLIconWinPath>C:\MyApp\MyApp.ico</RuntimeVLIconWinPath>
      </RuntimeVL>
    </SourcesFiles>
  </BuildApp>
</Preferences4D>
CléValeursDescription
RuntimeVLIncludeItTrue / FalseDoit être à True pour inclure le 4D Volume Desktop désigné par les clés suivantes
RuntimeVLWinFolderCheminDossier de 4D Volume Desktop pour Windows
RuntimeVLMacFolderCheminPackage de 4D Volume Desktop pour macOS
RuntimeVLIconWinPathCheminIcône de l'application pour Windows (.ico)
RuntimeVLIconMacPathCheminIcône de l'application pour macOS (.icns, le fichier info.plist est mis à jour)
IsOEMTrue / FalseInclure les licences de déploiement OEM

RuntimeVLWinFolder et RuntimeVLMacFolder sont obligatoires si BuildApplicationSerialized vaut True. Sinon, une erreur est retournée et la génération est interrompue.

Si une clé d'icône est omise, l'icône par défaut de 4D Volume Desktop est utilisée. Voir aussi Personnaliser les icônes d'une application.

Application client/serveur (CS)​

<Preferences4D>
  <BuildApp>
    <SourcesFiles>
      <CS>
        <ServerIncludeIt>True</ServerIncludeIt>
        <ServerWinFolder>C:\4D\4D Server\</ServerWinFolder>
        <ClientWinIncludeIt>True</ClientWinIncludeIt>
        <ClientWinFolderToWin>C:\4D\4D Volume Desktop\</ClientWinFolderToWin>
      </CS>
    </SourcesFiles>
  </BuildApp>
</Preferences4D>

Serveur​

CléValeursDescription
ServerIncludeItTrue / FalseDoit être à True pour inclure le 4D Server désigné par les clés suivantes
ServerWinFolderCheminDossier de 4D Server pour Windows
ServerMacFolderCheminDossier de 4D Server pour macOS
ServerIconWinPathCheminIcône du serveur pour Windows (.ico)
ServerIconMacPathCheminIcône du serveur pour macOS (.icns, le fichier info.plist est mis à jour)

ServerWinFolder et ServerMacFolder sont obligatoires si BuildServerApplication vaut True. Sinon, une erreur est retournée et la génération est interrompue.

Si une clé d'icône est omise, l'icône par défaut de 4D Server est utilisée.

Clients​

Les clés des clients sont nommées en fonction de la plate-forme de l'application cliente (ClientWin..., ClientMac...) et de la plate-forme de la machine de génération (...ToWin, ...ToMac, ...ForWinPath, ...ForMacPath).

CléValeursDescription
ClientWinIncludeItTrue / FalseDoit être à True pour inclure le client Windows désigné par ClientWinFolderToWin ou ClientWinFolderToMac
ClientWinFolderToWinChemin4D Volume Desktop pour Windows, lors d'une génération sous Windows
ClientWinFolderToMacChemin4D Volume Desktop pour Windows ou fichier .4darchive Windows, lors d'une génération sur macOS
ClientMacIncludeItTrue / FalseDoit être à True pour inclure le client macOS désigné par ClientMacFolderToMac ou ClientMacFolderToWin
ClientMacFolderToMacChemin4D Volume Desktop pour macOS, lors d'une génération sur macOS
ClientMacFolderToWinCheminFichier .4darchive macOS, lors d'une génération sous Windows
ClientWinIconForWinPathCheminIcône du client Windows (.ico), lors d'une génération sous Windows
ClientWinIconForMacPathCheminIcône du client Windows (.ico), lors d'une génération sur macOS
ClientMacIconForWinPathCheminIcône du client macOS (.icns), lors d'une génération sous Windows
ClientMacIconForMacPathCheminIcône du client macOS (.icns), lors d'une génération sur macOS
DatabaseToEmbedInClientWinFolderCheminDossier Windows contenant la structure compilée à intégrer dans un client monoposte
DatabaseToEmbedInClientMacFolderCheminDossier macOS contenant la structure compilée à intégrer dans un client monoposte
IsOEMTrue / FalseInclure les licences de déploiement OEM

Si une clé d'icône est omise, l'icône par défaut de 4D Volume Desktop est utilisée. Voir aussi Sélectionner l'archive cliente pour la plate-forme concurrente.

IsOEM​

Chemins XML
/Preferences4D/BuildApp/SourcesFiles/RuntimeVL/IsOEM
/Preferences4D/BuildApp/SourcesFiles/CS/IsOEM

Valeurs : True / False (défaut)

Si True, l'application générée (monoposte ou client/serveur, selon le nœud) inclut les licences de déploiement OEM. Sinon, l'application est générée en mode démo. Cette clé nécessite une licence OEM.
